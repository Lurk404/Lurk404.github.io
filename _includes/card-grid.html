Styles: _sass/portfolio/_custom.scss, "Cards". {% include card-grid.html items=site.data.published-work.books heading="h3" covers=true %} items the cards to show, in order (see the data file for the fields) heading the heading level for each card's title (default h2). Use one level below the heading the grid sits under. covers covers=true for book covers: narrower cards, and the whole cover shown in book proportions (3:4) Links to other websites open in a new tab on their own (assets/js/site.js, section 5). new_tab: true does the same for a link on lurk404.github.io, such as the AT User Guides, which the script would otherwise treat as part of this site. Either way, the script adds the new-tab icon and "(opens in new tab)" for screen readers. The whole card is clickable, but only the title is a link, so screen readers hear each card once.
