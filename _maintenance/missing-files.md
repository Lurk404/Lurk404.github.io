# Files to bring over from WordPress

The pages were converted from the WordPress export, which only has links to images and files, not the files themselves.
Each page already points to where its file should go, so a file starts showing as soon as it's added to the right folder with the right name.

**How to add them:** download each file from the WordPress Media Library (or the original address below), then upload it to the folder in the "Goes in" column, keeping the file name exactly as listed.

Tip: the folders mirror WordPress's own `uploads/YEAR/MONTH/` structure, so if you can download the whole uploads folder, its contents go into `assets/images/wp/` (images) and `assets/files/wp/` (PDFs and other files) as they are.

This folder (`_maintenance`) is not part of the website.

## Notes

- On the Curriculum Vitae page, the "JAWS (PDF, 254KB)" link points to a PNG image (`FreedomScientific-JAWS_2023_Certificate.png`), as it did on WordPress. If there's a PDF version, upload that instead and update the link.
- Some images on WordPress were resized copies (for example `name-1024x902.png`). The pages now point to the original file name without the size, which is what the Media Library downloads.
