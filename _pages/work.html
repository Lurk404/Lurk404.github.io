Accessibility demonstrations

Short, practical examples I use in workshops to show how content works (or doesn't) with assistive technology.

  • Alt text comparison: the same image with no alt text, unhelpful alt text, effective alt text, and a caption, plus a screen reader recording of all four.
  • Better links: link text that works for a screen reader user, shown side by side with link text that doesn't.
  • Images with text overlay: putting a screenshot's instructions on top of it as real text, instead of hiding them in alt text.
  • Accessibility Why: inaccessible colour, captions, alt text, and links, as an assistive technology user meets them (ETUG 2026).
