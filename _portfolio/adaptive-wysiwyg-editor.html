An attempt at a "what you see is what you get" (WYSIWYG) editor that creates accessible content and helps authors build a style sheet they can reuse.

If it were easier for authors to make accessible content, more content would be accessible. This project specifically relates to the Authoring Tool Accessibility Guidelines.
