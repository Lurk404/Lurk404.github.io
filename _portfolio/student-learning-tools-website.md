## The migration

I led the move of the Student Learning Tools website to the college's Drupal platform, end to end:

1. A content audit of the existing site.
2. A briefing note setting out the case and the plan.
3. Information architecture and mockups.
4. Building the pages, and commissioning a set of icons for them.
5. Fixing layout defects and reviewing every page on mobile.
6. Coordinating go-live.

## Web work since

- I build and maintain Drupal pages for other teams, including the ePortfolio awards site, the PebblePad page, and a Learning Technology hub.
- I'm the backup iWeb and Drupal administrator when a colleague is away.
- I test components in the college's Drupal design system for accessibility problems, such as faulty ARIA, and report them to developers with video recordings that show exactly what goes wrong.
